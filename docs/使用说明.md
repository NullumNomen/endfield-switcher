# 终末地版本切换器 2.0 · Rust / Git

双击 **EndfieldSwitcher.exe**。界面、版本识别、更新适配和文件切换均由 Rust 实现，不需要 Python、PowerShell 或 .NET。

程序使用本机已安装的 Git：`C:\Program Files\Git\mingw64\bin\git.exe`。整个 `EndfieldSwitcher` 文件夹需要一起保留；尤其不要删除 `data/repository.git`。游戏路径和 Git 路径在 `config.json` 中。

## 使用

1. 退出游戏和终末地官方启动器。Epic Games 客户端可保持打开。
2. 打开切换器，查看当前平台、游戏版本、Steam Build、官方分发包版本和 Git 快照编号。
3. 点 **切换到 Steam** 或 **切换到 Epic / 官方**，等待操作完成。若切换前 Steam 正在运行，程序会正常退出 Steam，并在操作结束后重新打开；原本未运行时不会额外打开 Steam。Steam 在 45 秒内未能退出时会停止切换，不会强制结束进程。
4. 点 **启动当前版本**。Epic 模式通过 Epic 游戏入口打开官方启动器，再点“开始游戏”。支付前请确认结算入口确实是你需要的平台。

**游戏版本和分发包版本不是同一个字段。** 例如本次实测：游戏自身显示 `1.6.3`，官方分发包为 `1.6.4`。

## 自动更新适配

打开切换器时检查一次版本，窗口闲置时不再定时检查。切换和启动前仍会检查，也可手动点击适配更新。

检测依据包括当前程序文件哈希、Steam Build 和内容清单编号、共享文件标记以及 VFS 资源目录的文件大小与修改时间。发现变化后，不会直接用旧文件覆盖新版。

打开时若游戏、Steam 或官方启动器还在运行，自动适配会暂停。退出后可手动适配或重新打开切换器；切换操作会自动退出并恢复 Steam。可安全处理时，切换器会自动：

- 读取本机 Steam 内容清单和官方 HTTPS 分发包的文件列表。
- 必要时启动 Steam 校验、补齐 Steam 文件，然后关闭本工具启动的 Steam。
- 重新比较实际差异，复用 Git 里已有的文件对象，只下载缺少的官方差异文件。
- 将两平台的新快照一起发布到本地 Git 分支，再恢复你选择的平台。

适配新版需要网络，也可能需要下载两平台的差异；大版本更新所需时间和空间取决于实际差异大小。平时切换已适配的版本无需下载。

断网或操作中断时会留下恢复记录。重新打开后会续接适配；若提示有未完成的文件切换，点 **恢复未完成的切换**。保留所有 `*.pending.json` 文件和 Git 仓库，完成恢复前不要手动删除。

如果官方更换了下载协议、清单格式，或本机文件无法归属到 Steam／官方包，程序会显示具体原因并保留快照，不会把未知文件强行当作完整版本。

## Git 如何管理文件

使用的是真正的本地 Git 仓库，完全不需要 GitHub 或联网推送：

- `steam` 和 `epic` 两条分支分别记录平台差异快照。
- Git blob 保存文件内容，相同内容只存一次；打包压缩可进一步利用二进制差异。
- 快照包含文件哈希、缺失文件标记、游戏版本、Steam Build、Steam 清单编号和共享文件校验标记。
- 两条平台分支通过一个 Git 引用事务一起更新，避免只更新了一边。
- **差异快照历史** 按钮显示历史提交；版本快照不可变。
- 切换前先把目标 Git 对象读到游戏所在盘并校验，再在同一磁盘原子替换文件。失败时从切换前快照恢复。

仓库只保存平台差异，**不是整套游戏资源的 Git 备份**。两平台资源暂时不一致时，资源差异也会纳入快照。默认每个平台保留最近 3 份快照，超出后自动裁剪并回收旧对象。HistoryLimit 可配置为 1–20。相同内容不重复提交；存在未完成事务时禁止清理。compact 命令按此策略立即整理。

账号、日志和额外的非受管文件不加入版本快照。切换器不会充值、购买或绑定账号。受管平台配置以各分支的 `.switcher-manifest.json` 为准。

## 游戏目录

资源主体只有一份：

`D:\SteamLibrary\steamapps\common\Arknights Endfield`

Epic 的两个历史路径通过目录联接指向上述目录。切换时共用资源，替换平台差异文件。

两平台入口共用同一目录。不要通过任一平台卸载或清空这个共享目录。更新或修复前先切到对应平台；完成后让切换器重新识别和适配。

## 源码和命令行

`rust-src/` 包含 Rust 源码、Cargo.toml 和锁定的 Cargo.lock。

```powershell
.\EndfieldSwitcher.exe inspect
.\EndfieldSwitcher.exe steam
.\EndfieldSwitcher.exe epic
.\EndfieldSwitcher.exe refresh
.\EndfieldSwitcher.exe recover
.\EndfieldSwitcher.exe history
.\EndfieldSwitcher.exe compact
```

直接查看仓库：

```powershell
git --git-dir=.\data\repository.git log --all --oneline
git --git-dir=.\data\repository.git show steam:.switcher-manifest.json
git --git-dir=.\data\repository.git show epic:.switcher-manifest.json
```

不要对游戏目录自行执行 `git reset --hard` 或手动改分支引用；切换器负责跨平台文件校验、共享资源兼容检查和事务恢复。
